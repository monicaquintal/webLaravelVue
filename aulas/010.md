<h2 id="topico1">1. Implementando o cadastro de fornecedores parte 1</h2>

- em `resources/views/app`, criar um novo diretório `fornecedor`, onde centralizaremos as views de fornecedores.
    - arrastar a `view fornecedor.blade.php` para este repositório, e renomear para `index.blade.php`.

- em `app\Http\Controllers\FornecedoresController.php`:

~~~php
class FornecedoresController extends Controller
{
    public function index() {
        return view('app.fornecedor.index');
    }
}
~~~

~~~css
.titulo-pagina-2 {

}
~~~

- ajustar a rota **Listar** em `routes/web.php`:

~~~php
Route::get('/fornecedor', [\App\Http\Controllers\FornecedoresController::class, 'index'])->name('app.fornecedor');
    Route::post('/fornecedor/listar', [\App\Http\Controllers\FornecedoresController::class, 'listar'])->name('app.fornecedor.listar');
~~~

- em `app/Http/Controllers/FornecedoresController.php`:

~~~php
class FornecedoresController extends Controller
{
    public function index() {
        return view('app.fornecedor.index');
    }

    public function listar() {
        return view('app.fornecedor.listar');
    }
}
~~~

- ajustar a rota **Novo** em `routes/web.php`:

~~~php
    Route::get('/fornecedor', [\App\Http\Controllers\FornecedoresController::class, 'index'])->name('app.fornecedor');
    Route::post('/fornecedor/listar', [\App\Http\Controllers\FornecedoresController::class, 'listar'])->name('app.fornecedor.listar');
    Route::get('/fornecedor/adicionar', [\App\Http\Controllers\FornecedoresController::class, 'adicionar'])->name('app.fornecedor.adicionar');
~~~
