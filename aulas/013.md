<h2 id="topico1">1. Introdução ao Vue.JS</h2>

### O que é o Vue.JS?

- framework JavaScript
- código fonte aberto
- criação de interfaces de usuário (front-end)
- aplicações de página única (SPA - Single Page Application)

### Algumas vantagens:

- manipulação simplificada do DOM
- reatividade e sincronia de estado
- divisão de interfaces em componentes
- leve
- comunidade ativa

<h2 id="topico3">3. Iniciando o nosso primeiro front-end com Vue</h2>

- há 3 formas de adicionar o framework Vue.JS ao projeto:
    - **download** nas versões de desenvolvimento ou produção.
    - **link CDN** (content delivery network ou rede de distribuição de conteúdo):
        - prototipação ou aprendizado: retorna a versão mais atual do framework.
        - produção: versão fixa do framework.
    - **CLI** (comand line interface ou interface de linha de comando).

### Para ter acesso ao framework via download ou CDN:

- acessar o [site do Vue.js](https://vuejs.org/), podendo clicar na opção para traduzi-lo para o [português](https://pt.vuejs.org/).
- clicar em "começar", para ser redirecionado para a [documentação](https://pt.vuejs.org/guide/introduction.html).
- **Desenvolvimento vs. Produção​**:
    - a Vue fornece vários recursos para melhorar a experiência de programação: avisos para erros comuns e armadilhas, propriedades / validação de eventos, gatilhos de depuração da reatividade, integração com ferramentas de programação
    - no entanto, estas funcionalidades tornam-se inúteis em produção. Algumas das verificações de alerta também podem gerar uma pequena sobrecarga de desempenho. 
    - ao implementar em produção, devemos eliminar todas as ramificações de código escritos para executar apenas em desenvolvimento e não usados em produção, para obter um tamanho de carga útil menor e um melhor desempenho.
- **cdn**:
    - podemos usar a Vue diretamente a partir duma rede de entrega de conteúdo através dum marcador script:

~~~html
<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
~~~

### a) Criando o projeto e implementando o Vue via download:

- realizar download do arquivo da aula e adicionar ao [diretório VueJS](../code/VueJS/).

<h2 id="topico4">4. Primeiro App em Vue (instância de Vue e o double mustache)</h2>

- o vuejs é um framework utilizado para criar interfaces reativas usando componentes.
- trabalharemos com elementos html, já que estamos falando de front de desenvolvimento web.
- a lógica de programação será escrita em js, utilizando o recurso do vue.

> Ponto e vírgula (;) não é obrigatório ao final dos comandos, fica a critério do desenvolvedor!

~~~html
<body>
    <div id="app">
        {{ mensagem }} <!-- double mustache -->
    </div>
    <script>
        options = {
            el:'#app', // # para id e . para class
            data: { // guarda as variáveis/atributos reativos
                mensagem: 'Primeiro template controlado pelo Vue! :)'
            } 
        }
        const vm = new Vue(options); // vm = ViewModel
        console.log(vm);
    </script>
</body>
~~~

> Binding, em linguagem de programação, significa uma amarração ou uma ligação. Trata-se de uma vinculação de um nome a um valor ou comportamento.

- o mais comum é que esses oapâmetros sejam encaminhados diretamente na instância, como no exemplo:

~~~html
<body>
    <div id="app">
        {{ mensagem }}
    </div>
    <script>
        const vm = new Vue({
            el:'#app', 
            data: { 
                mensagem: 'Primeiro template controlado pelo Vue! :)' // string
            } 
        }); 
    </script>
</body>
~~~

<h2 id="topico6">6. Methods - Adicionando os nossos primeiros métodos a instância Vue</h2>

~~~html
<div id="app">
    Soma: {{ somar() }} <br>
    Subtração: {{ subtrair() }} <br>
    Multiplicação: {{ multiplicar() }} <br>
    Divisão: {{ dividir() }} <br>
    Número aleatório: {{ numeroAleatorio() }}
</div> 

<script>
    const vm = new Vue({
        el:'#app', 
        data: {},
        methods: {
            somar: function somar() { // sintaxe convencional (função nomeada)
                return 12 + 6;
            },
            subtrair: function(){ // função anônima
                return 12 - 6;
            },
            multiplicar: () => { // arrow function
                return 12 * 6;
            },
            dividir() { // método abreviado
                return 12 / 6;
            },
            numeroAleatorio: function numeroAleatorio() {
                return Math.random();
            }
        } 
    }); 
</script>
~~~

- utilizaremos no curso as arrow functions e a forma enxuta!

<h2 id="topico7">7. Methods - Recuperando atributos do data</h2>

- podemos inderir os dados no data{} e utiliza-los nas funções.
- a diferença encontra-se na **arrow function**, na qual esse método de `thin.n1` não funcionará devido ao contexto léxico.
    - se inserir `this.n1 * this.n2` na arrow function, não teremos sucesso em recuperar os valores contidos no data (retornará NaN).

~~~html
<script>
    const vm = new Vue({
        el:'#app', 
        data: {
            n1: 10,
            n2: 5
        },
        methods: {
            somar: function somar() { // sintaxe convencional (função nomeada)
                return this.n1 + this.n2;
            },
            subtrair: function(){ // função anônima
                return this.n1 - this.n2;
            },
            multiplicar: () => { // arrow function
                return this.n1 * this.n2; // contexto léxico
            },
            dividir() { // método abreviado
                return this.n1 / this.n2;;
            }
        } 
    }); 
</script>
~~~

<h2 id="topico8">8. Methods - O contexto léxico das arrow functions e o conflito de nomes</h2>

- `arrow functions` não são funções interessantes para criação de métodos, pois não fazem referência ao escopo do objeto (ficam conectadas ao escopo global ou da função).

~~~

<h2 id="topico10">10. Diretiva V-Bind - Sintaxe sugar e a sobreposição/encadeamento de valores</h2>

### a) Sintaxe sugar:

- podemos omitir a utilização do termo "v-bind", utilizando aoenas os dois pontos (:).

~~~html
<a :href="site">Site</a>
<p :class="cor">Entendendo a diretiva v-bind</p>
~~~

### b) Sobreposição de valores:

- caso o atributo se repita, o que prevalecerá será aquele localizado à direita.

~~~html
<a :href="site" href="www.site.com.br">Site</a>
<!-- O que prevalecerá será www.site.com.br -->
~~~

### c) Encadeamento de valores:

- quando estamos trabalhando com a propriedade class dos elementos html, geralmente temos várias classes que podem ser atribuídas.
- nesse caso, o vue tem a inteligência de pegar o conteúdo e atribui-lo, ainda que depois da utilização do bind.
- ou seja, não há sobreposição, e sim encadeamento de valores!
- exemplo:

~~~html
    <style>
        .rosa {
            color: palevioletred;
        }

        .negrito {
            font-weight: bold;
        }
    </style>

</head>
<body>
    <div id="app">
        <a :href="site">Site</a>
        <p class="negrito" :class="cor">Entendendo a diretiva v-bind</p>
<!-- Nesse caso, serão atribuídas ambas as classes: negrito e rosa -->
~~~

<h2 id="topico11">11. Utilizando expressões no data binding</h2>

- expressões são instruções que podem ser calculadas dentro dos binds.
- exemplo:

~~~html
<div id="app">
    {{ 2 + 2 }}
    <input v-bind:value="2 + 2">
</div> 

<script>
    const vm = new Vue({
        el:'#app', 
        data: {
            mensagem:'Expressão'
        }
    }); 
</script>

<!-- Em ambos os casos será exibido o número 4! -->
~~~

- podemos, ainda, utilizar operador ternário, como no exemplo:

~~~html
<head>
    <style>
        .rosa {
            background-color: palevioletred;
        }

        .azul{
            background-color: blue;
        }
    </style>

</head>
<body>
    <div id="app">
        <input v-bind:value="2 + 2" :class="1 == 1 ? 'rosa' : estilo">
    </div> 

    <script>
        const vm = new Vue({
            el:'#app', 
            data: {
               estilo: 'azul'
            }
        }); 
    </script>
</body>
~~~

<h2 id="topico12">12. Diretiva V-On - Manipulando eventos</h2>

- por meio da `diretiva v-on` temos condição de fazer binding para manipulação de eventos que podem ser capturados pelo javascript.

~~~html
body>
<div id="app">
    <input type="text" v-on:keyup="imprimirTexto">
    <button v-on:click="mensagemAlerta">Botão</button>
</div> 

<script>
    const vm = new Vue({
        el:'#app', 
        data: {

        },
        methods: {
            imprimirTexto() {
                console.log('Teste');
            },
            mensagemAlerta() {
                alert('Mensagem de Alerta!');
            }
        } 
    }); 
</script>
~~~

- há, ainda, a **sintaxe sugar** do v-on (forma enxuta), que consiste na `utilização do arroba (@)`.
- exemplo:

~~~html
<input type="text" @keyup="imprimirTexto">
<button @click="mensagemAlerta">Botão</button>
~~~
