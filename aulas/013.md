<h2 id="topico1">1. Introdução ao Vue.JS</h2>

### O que é o Vue.JS?

- framework JavaScript
- código fonte aberto
- criação de interfaces de usuário (front-end)
- aplicações de página única (SPA - Single Page Application)

### Algumas vantagens:

- manipulação simplificada do DOM
- reatividade e sincronia de estado
- divisão de interfaces em componentes
- leve
- comunidade ativa
