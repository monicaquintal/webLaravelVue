<h2 id="topico1">1. Entendendo o objeto Request</h2>

- `Request`: requisição que é feita por um cliente (um browser) para o backend da aplicação.
    - sempre que uma requisição é feita, como uma ação de envio de formuilário, de consulta de uma página ou de conexão com API, por exemplo, temos um Request.

- no terminal, utilizar o comando `php artisan serve`.
- acessar a **rota Contato**.
    - Inspecionar > aba Network exibe os detalhes da requisição.
    - o próprio framework Laravel tem inteligência para recuperar o Request e transformar em objeto, que será recebido no Controlador como um parâmetro, dentro do qual poderemos manipular de acordo com a necessidade.
- em `ContatoController.php`:

~~~php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class ContatoController extends Controller
{
    public function contato(Request $request) {
        dd($request);
        return view('site.contato');
    }
}
~~~

- em `ContatoController.php` podemos incluir o **método all()**, que recupera o array associativo de parâmetros do Request:

~~~php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class ContatoController extends Controller
{
    public function contato(Request $request) {
        echo '<pre>';
        print_r($request->all());
        echo '</pre>';
        return view('site.contato', ['titulo' => 'Contato (teste)']);
    }
}
~~~

- ao invés de recuperar todos os dados com **all()**, podemos também utilizar o método **input()** para recuperar um dado específico, como no exemplo:

~~~php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class ContatoController extends Controller
{
    public function contato(Request $request) {
        echo '<pre>';
        print_r($request->all());
        echo '</pre>';
        echo $request->input('nome');
        echo '<br>';
        echo $request->input('email');
        return view('site.contato', ['titulo' => 'Contato (teste)']);
    }
}
~~~

<h2 id="topico2">2. Gravando os dados do formulário no banco de dados</h2>

- a primeira coisa que precisamos fazer é trazer pro contexto do script o modelo que fará todo o encapsulamento através do Eloquent ORM com a tabela no banco - nesse caso, o `Model SiteContato`.

~~~php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use App\Models\SiteContato;

class ContatoController extends Controller
{
    public function contato(Request $request) {
        echo '<pre>';
        print_r($request->all());
        echo '</pre>';
        echo $request->input('nome');
        echo '<br>';
        echo $request->input('email');
    }
}
~~~

- em `ContatoController.php`:

~~~php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use App\Models\SiteContato;

class ContatoController extends Controller
{
    public function contato(Request $request) {

        $contato = new SiteContato();
        $contato->nome = $request->input('nome');
        $contato->telefone = $request->input('telefone');
        $contato->email = $request->input('email');
        $contato->motivo_contato = $request->input('motivo_contato');
        $contato->mensagem = $request->input('mensagem');
  
        // print_r($contato->getAttributes());

        $contato->save();

        return view('site.contato', ['titulo' => 'Contato (teste)']);
    }
}
~~~

- além desse modelo, há uma outra forma; em `ContatoController.php`:

~~~php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use App\Models\SiteContato;

class ContatoController extends Controller
{
    public function contato(Request $request) {

        $contato = new SiteContato();
        $contato->fill($request->all());
        $contato->save();

        return view('site.contato', ['titulo' => 'Contato (teste)']);
    }
}
~~~

- para que funcione o método acima, devemos ir no Model `SiteContato.php`:

~~~php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Factories\HasFactory;

class SiteContato extends Model
{
    use HasFactory;
    
    protected $fillable = ['nome', 'telefone', 'email', 'motivo_contato', 'mensagem'];
}
~~~

> ao invés do método fill(), podemos utilizar o método create(), desde que adicionemos `protected $fillable`na model, como no exemplo abaixo; no arquivo `ContatoController.php`:

~~~php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use App\Models\SiteContato;

class ContatoController extends Controller
{
    public function contato(Request $request) {

        $contato = new SiteContato();
        $contato->create($request->all());

        return view('site.contato', ['titulo' => 'Contato (teste)']);
    }
}
~~~

<h2 id="topico3">3. Validação de campos obrigatórios (required)</h2>

- como validar os dados do formulário do lado do backend da aplicação?
- a validação de dados é muito importante para garantir o correto funcionamento da lógica do sistema, visto que dados obrigatórios (ou que devem possuir alguma característica específica) precisam ser validados ANTES de serem submetidos para outros processos dentro do sistema.
- neste momento, temos apenas um formulário dentro da aplicação, que é o `form_contato.blade.php`, que pode ser acessado através da Home ou da rota Contatos.

### a) Ajustando o código:

- em `routes` > `web.php`:

~~~php
<?php

use Illuminate\Support\Facades\Route;

Route::get('/contato', [\App\Http\Controllers\ContatoController::class,'contato']) -> name('site.contato');
Route::post('/contato', [\App\Http\Controllers\ContatoController::class,'salvar']) -> name('site.contato');
~~~

- em `app`> `Http` > `Controllers` > `ContatoController.php`:

~~~php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use App\Models\SiteContato;

class ContatoController extends Controller
{
    public function contato(Request $request) {

        // $contato = new SiteContato();
        // $contato->create($request->all());

        return view('site.contato', ['titulo' => 'Contato (teste)']);
    }

    public function salvar(Request $request) {
        SiteContato::create($request->all());

    }
}
~~~

### b) Validando os dados do formulário:

- há alguns detalhes importantes:
    - 1. no contexto das **Views** temos uma variável chamada `$errors`, que é disponibilizada pelo Laravel de modo automático para qualquer View; ela será afetada pelo nosso Controlador, então devemos determinar como lidar com essa variável.
    - 2. no nosso formulário, as colunas **nome**, **telefone**, **email**, **motivo_contato**, **mensagem**, **updated_at** e **created_at** são de preenchimento obrigatório!
        - portanto, antes de fazer a gravação com `SiteContato::create($request->all());`, devemos realizar a validação dos dados do formulário recebidos no request.

1. em `resources` > `views` > `site` > `layouts` > `_components` > `form_contato.blade.php`:

~~~php
<pre>
{{ print_r($errors) }}
</pre>
~~~

- obteremos o retorno:

~~~
Illuminate\Support\ViewErrorBag Object
(
    [bags:protected] => Array
        (
        )

)

~~~

2. iniciando a validação dos dados do formulário em `app`> `Http` > `Controllers` > `ContatoController.php`:
    - na validação, a chave utilizada será o name do input!

~~~php
public function salvar(Request $request) { 
        $request->validate([
            'nome' => 'required'
        ]);
    }
~~~

- nesse caso, será requerida a inserção do nome; caso não seja realizada, a variável $errors retornará:

~~~

3. incluindo required para todos os inputs de `form_contato.blade.php`, pois todos os campos do BD são obrigatórios:

~~~php
public function salvar(Request $request) {
    $request->validate([
        'nome' => 'required',
        'telefone' => 'required',
        'email' => 'required',
        'motivo_contato' => 'required',
        'mensagem' => 'required'
    ]);
}
~~~

<h2 id="topico4">4. Validação de quantidades mínimas e máximas de caracteres (min e max)</h2>

- na documentação do Laravel, acessar The basics > [Validation](https://laravel.com/docs/13.x/validation) > [Available Validation Rules](https://laravel.com/docs/13.x/validation#available-validation-rules).
    - [Required](https://laravel.com/docs/13.x/validation#rule-required).
    - [Min](https://laravel.com/docs/13.x/validation#rule-min).
    - [Max](https://laravel.com/docs/13.x/validation#rule-max).

- em `app`> `Http` > `Controllers` > `ContatoController.php`:
    - nomes com mínimo de 3 caracteres e máximo de 40 caracteres.

~~~php
public function salvar(Request $request) {
    
    $request->validate([
        'nome' => 'required | min:3 | max:40'
    ]);
}
~~~

- erros exibidos:
    - se deixar o campo nome vazio: "The nome field is required."
    - se preencher com menos de 3 caracteres: "The nome field must be at least 3 characters."
    - se preencher com mais de 40 caracteres: "The nome field must not be greater than 40 characters."

- ajustar também o imput mensagem:

~~~php
public function salvar(Request $request) {
    $request->validate([
        'nome' => 'required | min:3 | max:40',
        'telefone' => 'required',
        'email' => 'required',
        'motivo_contato' => 'required',
        'mensagem' => 'required | max:2000'
    ]);
}
~~~
